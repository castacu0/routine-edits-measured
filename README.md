# Routine Edits, Measured

Manuscript, committed data, figures and the code that regenerates them for

> Bravo, L., and Castanon Acuna, C. (2026). **Routine Edits, Measured: A Paired Evaluation of
> Perceptual-Hash Interdiction Under Non-Adversarial Transformations.** Preprint v1, prepared for
> arXiv (cs.CR). [`paper/ARXIV_V1_DRAFT.pdf`](paper/ARXIV_V1_DRAFT.pdf)

On 5,000 everyday photographs (COCO val2017), Meta's reference PDQ, the 64-bit pHash and a
block-mean hash are scored on the same edited copies under seven routine transformation families
at four intensities each. Non-geometric edits (JPEG, resize, blur, noise, brightness) leave
matching intact for all three hashes (0.0% to 0.1% residual). Geometric edits dominate: PDQ fails
to match 79.9% of center-cropped copies and 97.2% of rotated ones; a hash from a different
mathematical family fails substantially less on exactly those edits. Section 5.3 of the paper is a
dated, primary-sourced account of the image and video generators released in late October and
early November 2026 and what they change for hash-based interdiction.

This repository is the public mirror of the paper directory and research harness of the Violencia
Digital project (Fundación WomenCISO y MenCISO, I.A.P., Mexico City). The companion census of the
inter-image false-positive rate lives at [castacu0/pdq-census](https://github.com/castacu0/pdq-census).

## Regenerate everything

```bash
python3 -m venv .venv-research && .venv-research/bin/pip install -r research/requirements.txt
# the measurement (25 minutes on one laptop core; the corpus stays outside the repository)
.venv-research/bin/python research/run.py --corpus ~/datasets/val2017 --routine --limit 5000 --seed 1 --i-confirm-benign-corpus
# figures, tables and the PDF from the committed results file
python3 paper/build_arxiv.py
```

`paper/build_arxiv.py` regenerates Figures 1 to 3 and every table from `paper/data/*.json`, checks
the numbers quoted in the prose against the JSON, refuses em-dashes, and prints the PDF with
headless Chrome. The run of record (2026-09-14) and its repetition (2026-11-08) produced identical
aggregates.

| Path | What |
|---|---|
| `paper/ARXIV_V1_DRAFT.src.html` | the manuscript source; `ARXIV_V1_DRAFT.html` and `.pdf` are built from it |
| `paper/data/routine-coco-val2017.json` | aggregate results of record (rates, intervals, test statistics; no hashes, no pixels) |
| `paper/data/frontier-models-2026.json` | dated generator releases behind Section 5.3, each with its primary source and access date |
| `paper/figures-en/` | Figures 1 to 3 (SVG), regenerated by `research/plot_routine.py` and `paper/plot_frontier.py` |
| `research/` | the harness: `run.py`, `vdlab/` (hashes, transforms, paired statistics with a known-answer self-test), `hash_corpus.py`, `COMPUTE.md` |
| `dossier/analysis/make_figures.py` | the figure style module the renderers import |

## Benign corpora only

The harness operates on ordinary photographs and refuses a corpus path inside the repository and a
run without `--i-confirm-benign-corpus`. It has never been pointed at abuse material and must not
be. No image, hash of an image, or image URL is in this repository; `scripts/check-custody.mjs`
enforces that on every publish. Questions that would require abuse material are answered inside an
authorised holder's environment under their governance, not here.
